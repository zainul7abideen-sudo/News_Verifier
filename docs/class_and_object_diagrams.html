1. Domain Architecture & Object-Oriented Foundations

SRA TruthGuard is engineered using a robust domain-driven object-oriented architecture designed for deterministic media ingestion, multimodal claim normalization, Google Gemini AI stance evaluation, and tamper-proof cryptographic audit tracking.

Core Architectural Goal: Provide a scalable, modular object model that decouples real-time media ingestion from heuristic stance analysis and forensic verification workflows.

1.1 Key Object-Oriented Patterns Applied

Design Pattern UML Implementation Component Architectural Rationale
Strategy Pattern IVerificationStrategy → TextForensicStrategy, VideoDeepfakeStrategy, DocumentOCRStrategy, UrlCorroborationStrategy Allows interchangeable runtime execution of verification algorithms based on input media modality without modifying client callers.
Singleton Pattern PIBGroundTruthDatabase, FactCheckerStore Guarantees a single synchronized in-memory and persistent source of truth for debunked rumors and official PIB circulars.
Factory Method VerdictFactory.createVerdict() Encapsulates the instantiation of VerificationVerdict instances, calculating sensationalism indexes and attaching SHA-256 seal certificates.
Observer Pattern ForensicTelemetryNotifier → UIStreamSubscriber Streams real-time 5-stage verification logs from the AI execution pipeline to the active holographic HUD in the client interface.

1.2 Domain Package Boundaries

  • Ingestion Package (sra.ingestion): Manages live RSS streams (NDTV, BBC, CNN, TOI, Al Jazeera), manual submissions, and claim normalization.
  • Forensic Core Package (sra.forensics): Interfaces with Google AI Studio (Gemini 3 Flash), calculates veracity matrix, and coordinates stance detection.
  • Ground Truth Package (sra.groundtruth): Interfaces with Press Information Bureau (PIB) records, RBI circulars, and official gazettes.
  • Security & Identity Package (sra.identity): Manages RBAC permissions (Super Admin, Senior Editor, Fact Checker, Standard User) and cryptographic SHA-256 fact certificates.
