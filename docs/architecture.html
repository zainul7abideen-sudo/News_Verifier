1. System Overview & Core Architectural Principles

The SRA TruthGuard platform is built as a decoupled, resilient, multi-tiered web application designed for high-throughput news aggregation, multimodal disinformation detection, and real-time investigative stance auditing.

Figure 1: SRA TruthGuard Multi-Tier Architectural Topology

2. Core Architectural Layers

  • 1. Presentation Tier (React 19 SPA): Developed with modern functional components, hooks (useState, useEffect, useCallback), and high-performance glassmorphism CSS. Supports dynamic news browsing, 1-click modal verification, and role-based staff operations.
  • 2. API & Engine Tier (Express 5): RESTful API server providing endpoints for verification (/api/factcheck/verify), news listing (/api/news), student certification (/api/students), queries (/api/tickets), and authentication (/api/auth).
  • 3. Intelligence Tier (Google AI Studio Gemini API): Performs stance detection, deepfake artifact scoring, governmental gazette cross-referencing, and structured JSON synthesis.
  • 4. Data & Persistence Tier: Hybrid persistence combining Supabase PostgreSQL cloud sync, browser localStorage cache, and transactional JSON document storage.

5. Security, Sessioning & Threat Mitigation

Security Domain Implementation & Mechanism Protection Objective
API Key Isolation Client and Server environment variables (.env / VITE_GEMINI_API_KEY) Zero public repository credential exposure
CORS & Origin Filtering Express cors() middleware with authorized origin headers Mitigate Cross-Site Scripting & unauthorized proxy requests
Input Sanitization Regex validation, trim normalization, and HTML tag stripping on RSS feeds Prevent injection attacks and malformed payload execution
Session Storage JWT mock tokens with persistent localStorage hydration State preservation across browser refreshes and tabs

6. Deployment & Infrastructure Architecture

  • Frontend Web App (Client): Deployed on Netlify / Cloudflare Edge CDN with automatic HTTPS, global caching, and single-page routing (netlify.toml redirects).
  • API Application Server: Node.js Express server running on port 5000 with modular routes (/api/students, /api/factcheck, /api/news, /api/tickets, /api/auth).
  • Cloud Intelligence Service: Google AI Studio API Endpoint (https://generativelanguage.googleapis.com/v1beta) communicating over encrypted TLS 1.3.
  • Static Assets & Media: Unsplash optimized image CDN + Lucide icon tree-shaken SVGs.
